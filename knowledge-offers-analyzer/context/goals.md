## Read order for a new task

1. Read this orientation, context/CURRENT.md, and the latest dated file in context/log/.
2. Open [[00-INDEX]] and follow the curated product and area maps.
3. Read the smallest relevant source of truth before opening code: vision, requirements, roadmap,
