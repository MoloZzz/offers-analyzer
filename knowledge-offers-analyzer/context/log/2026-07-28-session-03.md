# Session log - 2026-07-28 (03)

## Goal

Implement B23: persisted evaluation explanations for reproducible `/why` and calibration provenance.

## Changes

1. Added a compact `EvaluationExplanation` snapshot type and builder. Poll evaluations now stamp
   `ParameterSet` version, profile threshold, cohort key/tier/sample, fair-value base/adjusted values,
   mileage adjustment, raw/confidence/penalty/score, factor reasons, fired flags, and evaluation time.
2. Added `Listing.lastExplanation` and `Opportunity.explanation` jsonb columns with migration
   `1785261600000`. Every poll evaluation writes the listing snapshot; opportunities copy the same
   object when created.
3. Updated `/why` to prefer a stored explanation for known listings, rendering without source fetch or
   live recompute. Listings without a snapshot still use the existing live assessment fallback.
4. Extended cohort provenance with a stable key and tier. Live scoring behavior was not changed.
5. Post-delegation review fixed mojibake in the stored `/why` formatter and added a regression
   assertion for readable Ukrainian text + `ParameterSet`/threshold provenance.
