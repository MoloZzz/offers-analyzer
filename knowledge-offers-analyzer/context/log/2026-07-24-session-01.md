## Design decisions implemented

- **Hybrid schema**: extend hourly window table + new monthly state table (minimizes risk, backward compatible)
- **On-demand daily reset**: recalculation checked on each `tryConsume()`, not cron-based (atomic, no dependency)
- **Tier parameter in tryConsume()**: single consumption point, cutoff enforced centrally, backward compatible via default tier=1
- **Tier assignment at call site**: PollService (tier-1/2), AutoRiaSource search (tier-3), cohort cache (tier-5) — context-aware
- **Reserve releases 3 days before month end**: configurable via `reserveReleasesAt`, formula: `lastDayOfMonth - 3 days`
- **10% threshold for cutoff**: configurable via `rateBudgetCutoffThresholdPct`, conservative to preserve high-value requests
