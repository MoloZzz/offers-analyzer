# Session log - 2026-07-28 (04)

## Goal

Implement SPEC-009: budget observability and rollout guardrails for ADR-0009's monthly pool.

## Changes

1. Promoted the backlog note into the formal Spec Kit package
   `specs/009-budget-observability/` (spec, plan, data model, contract, checklist, tasks).
2. Added immutable `budget_activities` records for every allowed or denied source-budget attempt:
   semantic operation, optional profile, priority tier, cost, outcome, and denial reason.
3. Propagated attribution through polling searches/details, daily sweep pages, and on-demand
   checks; shared cohort averages remain explicitly profile-less rather than falsely attributed.
4. Added a pure current-month projection/reconciliation report and read-only Telegram `/budget`.
   It exposes remaining daily/monthly pool, reserve state, actual-vs-ADR-0009 allocation,
   profile/tier spend, deferred work, run-rate forecast, and evidence-gate verdict.
5. The gate is deliberately advisory: it requires current-month history, zero aggregate/ledger
   discrepancy, and no overforecast, then still requires human reforecast approval; it cannot
   enable SPEC-005 or profiles itself.

  6 suites / 29 tests.

  native fallback for searches.
