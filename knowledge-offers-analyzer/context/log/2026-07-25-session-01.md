## Fixes applied

1. **HTTP-429 back-off restored** (`rate-budget.service.ts`). Added in-memory `pausedUntil`
   (const `EXHAUSTED_COOLDOWN_MS = 5 min`); `markExhausted()` sets it, `tryConsume()` returns
   `false` while active. The dead legacy-hourly-row write is kept only as harmless observability.
   The prior behaviour (source's own 429 ignored by the monthly path) is gone. New fake-timer test.
2. **`/deal` wrong-listing-id fixed** (`deal-args.ts` + `telegram-bot.update.ts`). New pure
   `splitDealCommand(raw)` takes the first whitespace token as the link; `extractAutoId` now sees
   only that token, so a 6+-digit price (`sell=100200`) can no longer be mistaken for the auto_id.
   4 new unit tests.
3. **Float artifacts fixed** (`deal-margin.ts`). `realizedMargin` rounds to 2 decimals at source,
   cleaning both the `/deal` reply and `/deals` list. Fractional-cent test added.
4. **Non-atomic pool update fixed** (`rate-budget.service.ts`). Daily reset uses a targeted
   `stateRepo.update({...}, { dailyBudget, dailyUsed, lastDayCalculated })` instead of a full-entity
   `save()`, so a concurrent `poolUsed` increment can't be clobbered.
5. **Lint gate green** (was 65 errors / 14 warnings, `--max-warnings 0` failing).
   - `.eslintrc.cjs`: scoped `overrides` for `test/**/*.ts` turning off `no-explicit-any` + the four
     `no-unsafe-*` rules (mock/fake `any` is deliberate). **src stays fully strict** — user-chosen
     approach over ~34 manual casts. Recorded in [[coding-standards]].
   - 25 `require-await` fixed properly (`() => Promise.resolve(x)`, not bare `async` removal).
   - `import/order` auto-fixed (`eslint --fix`) across 4 src files + several tests.
   - Also fixed the mislabeled `rate-budget.spec.ts` test ("never denies tier-1" → asserts denial).
