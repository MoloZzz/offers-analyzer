## Findings worth acting on

1. **Central unvalidated hypothesis:** survivorship bias inflates the RIA
   fair-value anchor by an estimated 8–15%; today's alerts may be
   margin-negative after haggling. Falsification test = measuring `k`
   (spec 004 Phase B/C), earliest ~2026-08-13 (≥30 disappearance events per
   cohort, accruing since 2026-07-23). Phase B/C tasks are still stubs.
2. **No ground-truth loop closes on money.** RIA never exposes realized sale
   prices; `k` is inferred from disappearance (a proxy), and `DealOutcome` is
   single-operator manual entry — statistically meaningful margin data is
   months out, not weeks.
3. **Stale spec artifacts (violates DoD §4):** `specs/007-deal-outcomes/tasks.md`
   is 0/17 checked while the feature is shipped; `specs/002.../tasks.md` T010
   still says the "disappeared" passive signal is deferred, though spec 004's
   `DisappearancesService` now provides it.
4. **Stale vault claim:** `00-INDEX.md:47` still says "Project is at bootstrap
   stage — most notes are skeletons", contradicted by 10 ADRs, 5 specs and a
   live deployment. `backlog.md` B4 ("go live" pending) is likewise stale.
5. **Cannot run 24/7 unattended.** No Dockerfile for the app (compose has only
   Postgres), no CI workflow, no HTTP health endpoint, and no supervisor config
   (systemd/pm2/restart policy) despite [[0008-global-error-handling|ADR-0008]]
   deliberately calling `process.exit(1)` on fatal errors.
6. **Concentration risk:** AUTO.RIA is the sole data source *and* the sole
   fair-value benchmark. The `ListingSource` port exists with one adapter; no
   fallback is implemented (see [[alternative-sources]]).
7. **Quota reality:** ~200 new-listing detail fetches/day is the binding limit;
   the Kyiv ≤$15k niche measures ~17,900 active listings, so the valued stream
   is deliberately narrowed to `submittedWithin: 2`. Widening needs a paid tier
   whose **price is documented nowhere** — no cost model exists in the vault.
8. **Nothing commercial anywhere.** No pricing, market sizing, competitors or
   users beyond "the operator". This is a personal/internal tool.
