# Changelog

All notable changes to this kit are recorded here. Installed projects are copy-and-own; upgrading
them is a reviewed migration, not an automatic synchronization.

## [0.1.0] - 2026-08-02

### Added

- Portable core contract and null-adapter bootstrap profile.
- Clean-room templates for curated knowledge, product governance, decisions, specifications, and
  isolated session context.
- Documentation for the operating loop, additive migration, security boundaries, and adapters.
